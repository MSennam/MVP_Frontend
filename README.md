Por motivos de teste e gravação do vídeo, as seguintes linhas se encontram com "/" antes de scripts e styless:

 <link rel="stylesheet" href="/styles.css">
    <script src="/scripts.js"></script>

Para abrir no navegador basta retirar a "/":

<link rel="stylesheet" href="/styles.css">
    <script src="scripts.js"><script>
